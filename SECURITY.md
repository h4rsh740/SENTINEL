# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

SENTINEL takes security seriously. As a firewall for AI agents, vulnerabilities in our enforcement logic or bypasses are treated with high priority.

If you believe you have discovered a vulnerability in SENTINEL:
1. **Do not** report security vulnerabilities via public GitHub issues.
2. Email `security@sentinelfirewall.org` with detailed reproduction steps, policy examples, and action payloads.
3. You will receive an initial response acknowledging your report within 48 hours.
4. A fix will be developed and released within a coordinated disclosure window (typically 30 days or less).
